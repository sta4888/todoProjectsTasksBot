# todoProjectsTasksBot
Бот для сохранения задач в ТГ 




БД - SQLAlchemy PostgresQL
Docker
aiogram


в базе будет таблица 

Проект
title
created_at



 
задача
project (ссылаться на ID из таблицы проекта)
task_text (текст задачи)
Done (булево значение, которое отвечает за выполненность задачи или нет)
task_type (тип задачи, срочная она или безсрочная и тп..) можно сделать отдельной таблицей или же сделать словарем
remind_time (уведомлять) это поле отвечает за время уведомления, так или иначе, когда и восколько начать уведомлять о задаче
remind_off (отключить уведомления) булево значение, отключить уведомления [если потом понадобится, то можно еще добавить поля для уведомлений и работы с ними, выключатели, поминутные уведомления и ТП]
